# Word Count Activity Heatmap

A simple GitHub-style heatmap of words written per day. Click a day to see words written and removed, and files created and removed.

Open it from the ribbon or the command palette. Choose which folders to track in the plugin settings.

Works somewhat with obsidian sync if the plugin is on both devices before writing but the synced data will look as if it were written on the day the sync happened.
